# Operator captures ([SCREENGRAB: slug])

Real screenshots and short screen-records the operator supplies land here as
`<slug>.png` (jpg/webp accepted) or `<slug>.mp4` (mov/mkv/webm accepted).

The flow: a LONG script may carry `[SCREENGRAB: slug]` for something real on
a screen: a broker app, a P&L, a search result. Pre-render validation BLOCKS
until the file exists. Upload it in the bot chat (the file name must be the
slug) or drop it here directly. Images are composed to fill the frame over
a blurred cover of themselves, clips are pad-fitted onto the kit's ground,
and both are normalized into the cache; the originals here are never
modified.

There is no `[ASSET]` tag any more: bespoke designed visuals come from the
kit's own plates, named with `[PLATE: …]`.
