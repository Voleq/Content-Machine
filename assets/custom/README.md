# Custom assets ([ASSET: slug])

Bespoke designed visuals land here as `<slug>.png` (jpg/webp accepted).

The flow: a LONG script may carry `[ASSET: slug]` plus an appended,
ready-to-paste Claude Design prompt. Pre-render validation BLOCKS until
the file exists — paste the prompt into Claude Design, export a 16:9 PNG,
and upload it in the bot chat (the file name must be the slug) or drop it
here directly. Bespoke visuals go through Claude Design on purpose —
never an image-generation API. Promote genuinely reusable ones into the
shared kit.
